# Contributing

Discuss changes in an issue before changing the experimental protocol. Keep raw evidence immutable, record dataset/model hashes and separate pilot tuning from held-out evaluation. Never commit real personal conversations, benchmark data, credentials or private manuscripts. Tests run with `python -m pytest -q`.

The owner-controlled project uses the MIT License. Contributions must be your own work or have compatible documented permissions; do not submit third-party code without provenance. No publication, patent, acceptance or superiority claim should be added without supporting evidence.
